Fitur

Semua yang dibutuhkan untuk mencatat tanpa ribet.

Dibuat untuk catatan sehari-hari: cepat dibuka, tetap rapi, dan tidak bergantung pada koneksi internet.

Catatan & checklist

Tulis catatan bebas atau ubah jadi checklist. Perubahan tersimpan otomatis, jadi tidak ada tombol simpan yang terlewat.

Pencarian cepat

Cari di judul, isi catatan, item checklist, dan nama label. Hasil tetap instan meskipun catatanmu sudah banyak.

Label & organisasi

Beri warna pada label, pin catatan penting, arsipkan yang sudah selesai, dan pulihkan dari Sampah bila perlu.

Pengingat

Pengingat sekali, harian, mingguan, bulanan, atau tahunan. Jadwal disusun ulang setelah perangkat restart.

Sinkronisasi opsional

Hubungkan Google hanya jika kamu mau. Data digabung dua arah, dan versi yang bentrok disimpan sebagai catatan [Konflik].

Local-first

Fitur inti berjalan tanpa akun dan tanpa internet. Kamu tetap bisa mencatat saat sedang offline atau di tempat tanpa sinyal.

Privasi

Privasi bukan fitur tambahan.

Catatan Fleksibel tidak punya server aplikasi, tidak memakai analytics, dan tidak menampilkan iklan. Data utamamu disimpan di database lokal di perangkat.

  • Tanpa akun untuk memakai fitur inti.
  • Tidak ada penjualan atau penyewaan data.
  • Token akses tidak ditulis ke database aplikasi.
  • Sinkronisasi hanya aktif setelah kamu memberi izin.

Baca kebijakan privasi

Scope yang diminta hanya drive.file

Aplikasi tidak bisa melihat seluruh Drive kamu. Ia hanya bisa mengakses file yang ia buat sendiri, atau file yang kamu buka lewat aplikasi ini.

Di Android, token dikelola oleh Google Sign-In. Di desktop, token akan disimpan di secure storage sistem operasi, bukan di database catatan.

Sinkronisasi

Satu spreadsheet, milikmu sendiri.

Kalau kamu mengaktifkan sinkronisasi, Catatan Fleksibel membuat atau menemukan spreadsheet Catatan Fleksibel - Data di Google Drive-mu. Tidak ada server perantara.

Alurnya sederhana

  1. Hubungkan Google. Pilih akun dan setujui akses drive.file.
  2. Buat catatan seperti biasa. Data tetap tersimpan lokal lebih dulu.
  3. Sinkronkan. Aplikasi mengirim perubahan, mengambil perubahan lain, lalu menggabungkannya.

Pelajari cara data Google diproses

Yang disinkronkan

  • Catatan dan isi checklist
  • Label dan relasi catatan–label
  • Pengingat dan status selesainya
  • Metadata urutan dan waktu perubahan

Catatan: sinkronisasi bukan pengganti backup. Spreadsheet tetap milikmu, jadi kamu bisa mengunduh atau menyalinnya kapan saja. Versi yang bentrok tidak dihapus diam-diam; aplikasi menyimpannya sebagai catatan [Konflik].

Pertanyaan umum

Hal yang sering ditanyakan.

Apakah data saya dikirim ke server kalian?

Tidak. Catatan Fleksibel tidak mengoperasikan server aplikasi. Data disimpan di perangkatmu. Jika kamu mengaktifkan sinkronisasi, data disalin ke spreadsheet Google Drive milikmu sendiri melalui Google API.

Apakah saya harus punya akun Google?

Tidak, untuk fitur inti. Akun Google hanya diperlukan jika kamu ingin memakai sinkronisasi ke Google Sheets.

Apa yang bisa dilihat aplikasi di Drive saya?

Aplikasi meminta scope drive.file, jadi hanya bisa mengakses file yang ia buat sendiri atau file yang kamu buka lewat aplikasi ini. Aplikasi tidak bisa membaca seluruh isi Drive.

Apakah ada analytics atau iklan?

Tidak ada analytics penggunaan, tidak ada iklan, dan tidak ada penjualan data. Situs ini juga tidak memakai cookie atau script pelacak.

Bagaimana cara menghapus data saya?

Hapus catatan dari aplikasi, kosongkan Sampah, lalu putuskan akun Google bila kamu memakai sinkronisasi. Spreadsheet di Drive tetap ada sampai kamu menghapusnya sendiri. Menghapus data aplikasi atau melakukan uninstall juga menghapus database lokal.

Bagaimana cara melaporkan bug atau memberi masukan?

Buka GitHub Issues. Jangan menyertakan isi catatan pribadi, token, atau alamat email di issue publik.
