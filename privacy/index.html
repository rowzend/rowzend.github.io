Kebijakan Privasi Catatan Fleksibel

Terakhir diperbarui: 12 November 2026

← Kembali ke beranda

Singkatnya: Catatan Fleksibel adalah aplikasi local-first. Kami tidak menjalankan server aplikasi, tidak memakai analytics, tidak menampilkan iklan, dan tidak menjual data. Catatanmu disimpan di perangkatmu. Jika kamu mengaktifkan sinkronisasi, data disalin ke spreadsheet Google Drive milikmu sendiri.

Kebijakan ini menjelaskan bagaimana aplikasi Catatan Fleksibel (“aplikasi”, “kami”) memproses informasi saat kamu memakai aplikasi Android, Linux, atau Windows, serta situs rowzend.github.io. Dengan memakai aplikasi, kamu menyetujui praktik yang dijelaskan di sini.

1. Siapa yang bertanggung jawab

Catatan Fleksibel dikembangkan oleh proyek independen rowzend. Untuk pertanyaan privasi, gunakan kanal kontak di bagian akhir kebijakan ini.

2. Data yang diproses

2.1 Data catatan

Saat kamu memakai aplikasi, data berikut dibuat dan disimpan di perangkatmu:

  • Judul, isi catatan, dan item checklist.
  • Label, warna, status pin, status arsip, dan status Sampah.
  • Pengingat: waktu, zona waktu, aturan pengulangan, dan status selesai.
  • Metadata teknis yang diperlukan agar data tetap konsisten, seperti ID catatan, waktu dibuat/diubah, dan penanda perangkat untuk sinkronisasi.

Data ini adalah data utamamu. Kami tidak memiliki akses ke data tersebut kecuali kamu secara eksplisit mengirimkannya kepada kami, misalnya saat melaporkan bug.

2.2 Data akun Google (hanya jika kamu menghubungkan akun)

Sinkronisasi bersifat opsional. Jika kamu menekan Hubungkan Google, aplikasi meminta izin untuk mengakses Google Drive dengan scope https://www.googleapis.com/auth/drive.file. Dari Google, aplikasi menerima:

  • Alamat email dan nama tampilan akun, untuk menampilkan akun yang sedang terhubung.
  • Akses ke file yang dibuat atau dibuka oleh aplikasi di Drive, sebatas yang diizinkan scope drive.file.

Email dan nama tampilan ditampilkan selama sesi aplikasi. Aplikasi tidak menyimpannya sebagai bagian dari database catatan. Status “pernah terhubung” disimpan sebagai preferensi lokal sederhana agar aplikasi tahu apakah sync perlu ditawarkan saat dibuka.

2.3 Token dan kredensial

Token akses Google tidak ditulis ke database catatan dan tidak dimasukkan ke spreadsheet. Di Android, token dikelola oleh Google Sign-In. Pada versi desktop yang mendukung sinkronisasi, token disimpan di secure storage sistem operasi (misalnya Secret Service/libsecret di Linux dan Credential Manager di Windows). Aplikasi tidak menyimpan token dalam bentuk plaintext.

2.4 Data diagnostik (opsional)

Jika versi aplikasi yang kamu pakai menyediakan pelaporan crash, fitur tersebut nonaktif secara default dan hanya aktif setelah kamu memilih untuk mengaktifkannya. Laporan crash dapat berisi informasi teknis seperti stack trace, versi aplikasi, versi sistem operasi, dan model perangkat. Sebelum dikirim, konten catatan, label, alamat email, dan token disaring. Aplikasi tidak mengirim analytics penggunaan, tidak melacak aktivitas mengetik, dan tidak membaca isi catatan untuk keperluan iklan.

2.5 Data situs web

Situs ini adalah halaman statis yang dihosting di GitHub Pages. Situs tidak memasang cookie, tidak memuat analytics, dan tidak menjalankan script pelacak. GitHub sebagai penyedia hosting dapat memproses log teknis (seperti alamat IP dan user agent) sesuai Kebijakan Privasi GitHub.

3. Penyimpanan lokal

Database utama disimpan di direktori data privat aplikasi di perangkat. Aplikasi tidak memakai enkripsi tingkat aplikasi untuk database tersebut; perlindungannya mengikuti sandbox aplikasi, enkripsi disk, dan kunci layar perangkat. Jika perangkatmu dipakai bersama, aktifkan kunci layar dan pertimbangkan enkripsi perangkat.

4. Sinkronisasi Google Drive dan Sheets

Sinkronisasi hanya berjalan setelah kamu menghubungkan akun Google dan memberikan izin. Saat sync aktif:

  • Aplikasi mencari spreadsheet bernama Catatan Fleksibel - Data di Drive-mu, atau membuatnya jika belum ada.
  • Aplikasi menulis dan membaca tab spreadsheet untuk catatan, checklist, label, relasi label, dan pengingat.
  • Data berpindah langsung antara perangkatmu dan Google Drive. Kami tidak memiliki server perantara dan tidak menerima salinan data tersebut.
  • Google memproses data sesuai Kebijakan Privasi Google dan syarat layanan Google Drive.

Kamu dapat memutuskan akun kapan saja di Pengaturan, mencabut izin aplikasi di myaccount.google.com/permissions, dan menghapus spreadsheet langsung dari Google Drive.

Google API Services User Data Policy

Penggunaan dan transfer oleh Catatan Fleksibel atas informasi yang diterima dari Google API akan mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use. Data Google tidak digunakan untuk iklan, tidak dijual, dan tidak dibagikan kepada pihak ketiga selain yang diperlukan untuk menyediakan fitur sinkronisasi yang kamu minta.

5. Berbagi data

Kami tidak menjual, menyewakan, atau memperdagangkan datamu. Data hanya dapat dibagikan dalam keadaan berikut:

  • Kepada Google, jika kamu mengaktifkan sinkronisasi. Ini diperlukan agar aplikasi dapat menulis dan membaca spreadsheet di Drive-mu.
  • Kepada penyedia pelaporan crash, hanya jika kamu mengaktifkan fitur opsional tersebut.
  • Jika diwajibkan hukum, atau untuk melindungi hak, keamanan, dan integritas pengguna.
  • Atas permintaanmu, misalnya saat kamu mengirim laporan bug yang berisi informasi tertentu.

6. Keamanan

Kami berupaya menjaga data dengan membatasi scope Google, menggunakan koneksi HTTPS untuk API Google, tidak menulis token ke database, dan memakai secure storage untuk token di desktop. Namun, tidak ada sistem yang sepenuhnya aman. Kamu juga bertanggung jawab menjaga keamanan perangkat, akun Google, dan file spreadsheet milikmu.

7. Retensi dan penghapusan

  • Data lokal tetap ada sampai kamu menghapus catatan, mengosongkan Sampah, menghapus data aplikasi, atau melakukan uninstall.
  • Spreadsheet di Drive tetap ada sampai kamu menghapusnya sendiri dari Google Drive. Memutuskan akun di aplikasi tidak menghapus spreadsheet.
  • Laporan crash, jika diaktifkan, disimpan oleh penyedia sesuai kebijakan retensi mereka. Kamu dapat meminta penghapusan melalui kanal kontak di bawah.

8. Hak dan pilihanmu

  • Memakai fitur inti tanpa akun Google.
  • Menolak atau mencabut izin Google kapan saja.
  • Mengakses, mengoreksi, dan menghapus catatan langsung dari aplikasi.
  • Menghapus spreadsheet dari Google Drive.
  • Menonaktifkan pelaporan crash jika fitur itu tersedia.

9. Anak-anak

Aplikasi tidak ditujukan untuk anak di bawah 13 tahun. Kami tidak dengan sengaja mengumpulkan data pribadi dari anak-anak. Jika kamu mengetahui adanya data seperti itu, hubungi kami agar dapat ditindaklanjuti.

10. Perubahan kebijakan

Kebijakan ini dapat diperbarui jika fitur, penyedia layanan, atau persyaratan hukum berubah. Tanggal “terakhir diperbarui” di bagian atas halaman akan menunjukkan versi terbaru. Perubahan material akan dijelaskan di halaman ini.

11. Kontak

Untuk pertanyaan atau permintaan terkait privasi, buka GitHub Issues. Jangan menyertakan isi catatan pribadi, token, atau alamat email di issue publik. Jika perlu membahas data sensitif, tulis permintaan singkat tanpa detail dan kami akan mengarahkan ke kanal yang lebih privat.

Dokumen ini adalah kebijakan privasi produk, bukan nasihat hukum. Jika kamu memerlukan kepastian hukum untuk yurisdiksimu, konsultasikan dengan profesional.
